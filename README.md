# Dr. Vishnu Bhuvanachandran — Portfolio

A professional portfolio for a PhD Mechanical Engineer and MSc Data Analyst.

## 🚀 Deployment Instructions

### How to deploy to your GitHub Pages site

1. **Replace your `index.html`** — Copy the new `index.html` from this download into your repository root.

2. **Replace `style.css` and `script.js`** — Copy these too (they're minimal since all core styles/scripts are embedded in index.html).

3. **Your profile photo** — Make sure `profile.jpg` is in the **root** of your repository (it's already there).

4. **Add your CVs** — Upload these PDF files to the **root** of your repository:
   - `Vishnu_PGIM_Resume.pdf` (Data Analyst CV)
   - `Vishnu_CV_Hanley.pdf` (Mechanical CAD Technician CV)
   - `Vishnu_UCD_019732.pdf` (Senior Research Fellow CV)
   - `Vishnu_MechEnngineer_.pdf` (Mechanical Project Engineer CV)

5. **Commit and push** — GitHub Pages auto-deploys. Your site will update at:
   `https://vishnuanalyst555.github.io`

## ✏️ Customisation tips

- To update your current role/employer: search for "Starilum" in index.html and update.
- To add a new project: copy any `.project-card` block and update content.
- To change contact details: search for the email/phone in the Contact section.
- Project category filters work via `data-cat` attribute on `.project-card`.
